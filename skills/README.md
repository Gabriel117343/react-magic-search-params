# Skills Folder

This folder contains reusable agent skills for projects that use `useMagicSearchParams`.

Recommended copy targets in consumer projects:

- `.github/skills/react-magic-search-params/SKILL.md`
- `.claude/skills/react-magic-search-params/SKILL.md`
- `.agents/skills/react-magic-search-params/SKILL.md`

Why this folder exists:

- Keep a portable skill source in this repository.
- Make it easy for other developers to copy the same guidance.
- Keep npm package output clean (this repository already publishes `dist` only).
